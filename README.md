# AI Text Sentiment Analyzer

## Project Overview
AI Text Sentiment Analyzer is a machine learning-based application that analyzes text and identifies its sentiment as Positive, Negative, or Neutral.

The project uses Natural Language Processing (NLP) and Machine Learning techniques to understand text and classify opinions.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- Streamlit
- Pandas

## Features
- Text sentiment classification
- Positive, Negative, and Neutral predictions
- Confidence score
- Sentiment probability visualization
- Interactive web interface

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AI-Text-Sentiment-Analyzer.git
```

2. Open the project directory:

```bash
cd AI-Text-Sentiment-Analyzer
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Train the machine learning model:

```bash
python train_model.py
```

5. Run the application:

```bash
streamlit run app.py
```

## Model Information
- Feature Extraction: TF-IDF
- Classification Algorithm: Logistic Regression
- Output Classes: Positive, Negative, Neutral
